# Collection Policy — 何を保存するか

自分に合わせて書き換えてよい。エージェントはこの基準と下の既定目的で資料を分類する。

## 保存するとき

次のどれかに当てはまるとき保存する。

- 授業の理解や試験対策に使える。
- 就活（業界・企業研究、選考の準備）に直接使える。
- ゼミ・研究の方法や解釈に役立つ。
- いまの考えを変える、または反論する根拠がある。
- 複数の科目・プロジェクトで繰り返し使える概念である。
- 興味がある分野の記事である（興味そのものが保存の理由になる）。

## 保存しないとき

- 既存のノートとほとんど同じ。
- 出典を確かめられない。
- 短い流行の情報で、長く使う価値がない。
- 読み返す可能性がとても低い。

## 必ず答える質問

集めた資料には次の問いへの答えを一文で書く（Web Clipper の `Why I saved this` 欄など。空なら既定目的を使う）。

なぜ今この資料を保存するのか？

## 既定の保存目的

資料ごとに目的を書いた場合はそちらを優先する。

| 資料の種類 | 既定の目的 |
|---|---|
| 授業 | その科目の理解や試験対策に使う。 |
| 就活 | 志望業界・企業の研究と選考の準備に使う。（志望業界が決まったら書き足す。例: 「IT業界の企業研究」） |
| ゼミ・研究 | 研究の方法と結果の解釈に使う。 |
| AI・新技術などの記事 | 興味で集める。目的が空でも保留せず保存し、就活中は就活での活用（業界構造、企業研究、選考の準備の材料、用語）の観点でも整理する。 |

- 分類がはっきりしていれば既定目的を使う。既定目的を使ったことは原文を直さず ingest-log の「既定目的を使ったか」欄にだけ書く。本人が言った個別の動機のように書かない。
- 分類が不明、または上の目的に合わなければ、目的を確かめるために保留する。
- `My initial thoughts` は本人が書く。空でも処理でき、AI が代わりに埋めない。
